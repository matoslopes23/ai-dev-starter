# Relatos de segurança

Não publique segredos, payloads com dados reais ou detalhes de uma vulnerabilidade explorável em uma issue pública. Use o recurso de relato privado de vulnerabilidade do GitHub, se estiver habilitado no repositório. Caso não esteja, peça ao mantenedor um canal privado sem divulgar os detalhes do problema. Este arquivo não habilita funcionalidades do GitHub nem estabelece um SLA.

Inclua versão/commit, ambiente, fronteira afetada, impacto e reprodução mínima com dados sintéticos. Para uma credencial exposta, siga o processo do responsável para revogação/rotação; não envie o valor ao mantenedor do kit.

O kit não é sandbox de execução. Scripts de origem, ferramentas, comandos de produto e avaliações com agentes continuam sujeitos à revisão e às permissões do ambiente. O scanner incluído é heurístico e não substitui auditoria nem análise do histórico.
